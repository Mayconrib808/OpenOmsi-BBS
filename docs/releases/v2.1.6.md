# OpenOmsi + BBS 2.1.6

PT-BR: Corrige a substituição automática do auxiliar do Bridge entre versões.
O Setup reconhece os auxiliares compilados do projeto pelos metadados do
executável, mantém um backup do anterior e restaura o arquivo se a ativação
falhar. Feche BBS, openOMSI e os auxiliares antes de instalar.

EN: Fixes automatic Bridge helper replacement across versions. Setup identifies
source-built project helpers using executable metadata, keeps the previous file
as a backup and restores it if activation fails. Close BBS, openOMSI and helpers
before installing.

DE: Behebt den automatischen Austausch des Bridge-Hilfsprogramms zwischen
Versionen. Setup erkennt die aus dem Projekt kompilierten Hilfsprogramme anhand
der Metadaten, sichert die vorherige Datei und stellt sie bei fehlgeschlagener
Aktivierung wieder her. Vor der Installation BBS, openOMSI und Hilfsprogramme
schließen.
