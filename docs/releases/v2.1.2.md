# Bridge 2.1.2 / Host 2.1.2-host.1

The Setup checks for a signed stable release in the background at startup. A checkbox enables or disables startup checks; its per-user preference survives reopening without requiring Bridge activation or a game configuration change. The manual button remains available when automatic checks are disabled. The user can check manually and install a verified release using the same automatic installer. The updater waits for Setup to exit, preserves installed paths/company configuration and reopens Setup after success. BCS, game and host must be closed. Distribution uses an isolated Cloudflare Worker with Static Assets, deployed using the existing GitHub Actions secrets. Only the seven Bridge binaries are compiled for the candidate; the native game/server build is excluded. Setup is compiled with the production HTTPS origin and the same sequence as the signed manifest. The deployment verifies the live manifest and installer hash before delivery. No publication key or Cloudflare credential belongs in the player package.

Next-trip preparation is included for native BCS installations: opening Setup with the configured BCS closed prepares the compatible observer automatically. Saving a native installation prepares it without requiring legacy registry interception. Unknown vendor builds are refused and the original JAR is backed up.

Includes native-live-next-trip-3 and the host's HTTP-202 submission fix. The actual native acknowledgment and matching timetable are required before starting the new evaluation baseline. A generic submission error must not leave a successfully applied duty with the old driver's evaluation frozen. The regression test drives the confirmed handoff through a real driver save and checks that new stops, distance and tickets are published to BCS.

Local Go tests, race checks, Lua companion checks, Worker checks, seven Windows cross-builds and package integrity checks are performed. Actual BCS finalization, UAC and Windows GUI handoff still require validation in Windows. The previous game session is not reconstructed from inferred counters.
