# OpenOMSI BCS Bridge 2.1.9.4

## Português

- Remove o bloqueio por versão e pelo hash do JAR inteiro do BCS. Alterações em recursos, empacotamento ou outras partes do BCS deixam de impedir Salvar e ativar.
- A extensão de log de Próxima viagem identifica a classe de dados pela interface instalada, inclusive quando o nome muda. Se a própria comunicação mudar, a Bridge permite a ativação e registra que essa extensão não foi aplicada. O JAR desconhecido é preservado; a integração poderá ser adaptada quando necessário.
- Suporta os servidores oficiais openOMSI 0.3.33 (protocolo 7) e 0.3.34 (protocolo 14), mantendo os protocolos 6 e 7 anteriores.
- As duas versões do openOMSI não podem compartilhar a mesma sessão: jogadores 0.3.33 precisam de servidor 0.3.33; servidor 0.3.34 exige jogadores 0.3.34. A Bridge preserva o protocolo real de cada sessão, a autenticação, os pacotes de sincronização e o servidor selecionado pelo administrador.

Atualização cumulativa com as correções anteriores, letreiro, próxima viagem e a opção de ligar o ônibus automaticamente. Feche BCS, openOMSI, Setup, HostAgent e CompanyHost e execute Atualizar-Bridge.exe. Empresa, convite, pastas e preferências são preservados. O atualizador não troca o jogo nem o servidor.

## English

- Removes the BCS version/whole-JAR hash gate. Resource and archive changes no longer block Save and activate.
- Finds the next-trip observer's state class through its installed method interface instead of a release hash. When that interface changes, activation remains available and diagnostics record that the logging extension was left unapplied. Unknown logger code is preserved.
- Supports official openOMSI 0.3.33 servers (protocol 7) and 0.3.34 servers (protocol 14), retaining previous protocol 6/7 support.
- Clients and servers must match: 0.3.33 clients cannot join a 0.3.34 server. Protocol, authentication, opaque synchronization packets and the administrator's chosen server remain intact.

Cumulative update including earlier recovery, destination, next-trip and automatic bus startup options. Close BCS, openOMSI, Setup, HostAgent and CompanyHost, then run Atualizar-Bridge.exe. Company, invitation, paths and preferences are preserved. Game and server binaries are not replaced.

## Deutsch

- Entfernt die BBS-Versionsprüfung und die Sperre anhand des gesamten JAR-Hashs. Änderungen an Ressourcen oder der Archivierung blockieren Speichern / aktivieren nicht mehr.
- Die Protokollerweiterung für die nächste Fahrt findet die Datenklasse anhand ihrer installierten Methodenschnittstelle. Bei einer geänderten Schnittstelle bleibt die Aktivierung möglich; das Diagnoseprotokoll vermerkt die nicht angewendete Erweiterung. Unbekannter Logger-Code bleibt erhalten.
- Unterstützt offizielle openOMSI-Server 0.3.33 (Protokoll 7) und 0.3.34 (Protokoll 14) sowie bisherige Protokolle 6/7.
- Spieler und Server benötigen passende Versionen: 0.3.33-Spieler können einem 0.3.34-Server nicht beitreten. Protokoll, Anmeldung, Synchronisierungspakete und die Serverauswahl des Administrators bleiben erhalten.

Kumulatives Update einschließlich Wiederherstellung, Zielanzeige, nächster Fahrt und automatischem Busstart. BBS, openOMSI, Setup, HostAgent und CompanyHost schließen und Atualizar-Bridge.exe starten. Firma, Einladung, Pfade und Einstellungen bleiben erhalten. Spiel und Server werden nicht ersetzt.

## Validation

Official SHA-256-verified Linux 0.3.33 and 0.3.34 server binaries passed the synthetic-map integration test: two absent private player buses, original filenames relayed, native stand-in, authenticated reconnect, unchanged user configuration. Gateway tests cover UDP/WebSocket transport and opaque session-bound packets. Portable Go tests/vet, all seven Windows cross-builds, helper/facade layout and full package integrity passed locally. Full BCS game trips still require testing in the installed games.
