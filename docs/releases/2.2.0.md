Bridge 2.2.0 includes the exact approved OpenOmsi Coop 0.3.38 Coop 6 portable
distribution in `OpenOmsi Coop 0.3.38` beside Setup.exe. The Setup button selects
its real game executable; an existing player selection is preserved until changed.

The cumulative automatic update preserves company and server settings. It embeds
the seven Bridge components and pins the Coop archive, its four immutable parts
and all 45 files. Downloads are cancellable, cached only after SHA-256 validation,
and verified before installation. A failure before installation leaves the current
Bridge intact. Installation retains the existing rollback and local-path checks.

The small installer remains compatible with the 64 MiB limit in old 2.1 Setup
clients. Each Coop part fits the 25 MiB static asset limit. The original Ed25519
publisher identity remains unchanged. The full ZIP already contains the game,
audio, app-local DLLs, AGPL notices and complete corresponding source.

Build with Go 1.23.2 and Python 3.11+: `python scripts/build_220.py --coop
Coop_6_Windows_x64.zip`. The four delivered 2.1.9.8 host/helper binaries are
preserved by exact hash because their latest source was not in that release
branch. The three player components are rebuilt from the included Go source.
The configured dedicated server is preserved; this player update does not
replace it. Coop 6 uses protocol 14, so a session's clients and server must match.

Windows GUI/startup and automated regressions are recorded separately from
gameplay. A real two-player session and BCS trip evaluation are not certified.
