# 2.1.3

Saving a configured native PeDePeAdapter installation now confirms successful
activation and next-trip preparation instead of restoring the initial instructions.
The startup preparation reports the same successful state. Check status reads
the BCS native selection and confirms the inspected next-trip logger hash;
legacy registry activation continues to use its existing status checks.

Status checking is read-only and never changes the vendor JAR. A configured
adapter with an unprepared logger is reported as requiring preparation, rather
than claiming successful activation.

Validated using the real inspected BCS JAR: unprepared, prepared without
registry activation, disabled native selection, read-only status and existing
legacy registry states. Update distribution remains optional on startup with
a manual check button.
