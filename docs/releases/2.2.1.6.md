# Bridge 2.2.1.6 — openOMSI 0.3.44 Coop15 (candidate)
This development candidate moves the complete audited 2.2.1.5 Coop15
source layer from official 0.3.43 to the exact official openOMSI 0.3.44
source changes. It retains bus driver handover, conductor/ticket controls,
passenger hailing and finger animation, BCS fuel, custom closing audio,
dynamic server P15, and the previous P14 server.

## Time and multiplayer
- Native authenticated server admins have minute-based clock controls.
- The HostAgent's **Allow admin clock changes after initial sync** option is off by
  default. When explicitly enabled, the BCS company time initializes the session
  but the dedicated server becomes authoritative after initial sync so that
  authorized native admin clock changes are not undone every 5 seconds.
- The original driver cannot manually recall a delegated bus. They become a
  passenger, may request conductor authorization, and the new driver alone
  may voluntarily return the wheel. A disconnected driver is still handled
  by the existing safety-recovery protocol.
- Coop/BCS, input, performance and package behavior still require real two-PC
  verification; an automated test pass does not certify in-game behavior.
