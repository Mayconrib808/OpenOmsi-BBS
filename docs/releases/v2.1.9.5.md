# OpenOMSI BCS Bridge 2.1.9.5

## Português

Corrige a passagem do Setup para o atualizador: depois de baixar e verificar a atualização e iniciar o atualizador, o Setup fecha a janela e encerra o próprio processo. Se o atualizador não conseguir iniciar, o Setup permanece aberto para mostrar o erro. O fechamento normal da janela também encerra o processo, evitando um Setup invisível no Gerenciador de Tarefas.

O atualizador solicita o fechamento normal dos Setups desta instalação e aguarda a saída deles antes de substituir arquivos. A identificação usa o caminho e a identidade do arquivo, não só o nome ou um PID antigo. Operações em andamento continuam protegidas e o processo não é finalizado à força.

Atualização cumulativa com todas as mudanças da 2.1.9.4: BCS sem bloqueio por versão/hash do JAR inteiro; servidores openOMSI 0.3.33 e 0.3.34; jogadores e servidor precisam de versões compatíveis. Configurações, empresa, convite e servidor escolhido são preservados.

Para instalar esta correção, feche BCS, openOMSI, HostAgent e CompanyHost e execute Atualizar-Bridge.exe. Se o Setup antigo já estiver preso sem janela, finalize esse processo antigo uma vez antes de aplicar a correção.

## English

Fixes the Setup-to-updater handoff: after downloading and verifying the update and successfully starting its updater, Setup closes its window and exits its own process. Launch failures leave Setup open to display the error. Normal window closure also exits the process, preventing an invisible Setup from remaining in Task Manager.

The updater requests normal closure of matching Setups from this installation and waits for their exit before replacing files. File identity and current process snapshots are used instead of trusting an old PID. Active operations remain protected; processes are never forcibly terminated.

Cumulative update including all 2.1.9.4 changes: no BCS version/whole-JAR hash gate; official openOMSI 0.3.33 and 0.3.34 servers; clients and server need matching protocols. Settings, company, invitation and selected server are preserved. Close the games and host applications, then run Atualizar-Bridge.exe. An older Setup already stuck without a window may need to be closed once in Task Manager to install this fix.

## Deutsch

Korrigiert die Übergabe vom Setup an den Updater: Nach dem Download, der Prüfung und dem erfolgreichen Start des Updaters schließt das Setup sein Fenster und beendet seinen eigenen Prozess. Bei einem Startfehler bleibt das Setup zur Fehleranzeige geöffnet. Auch normales Schließen beendet den Prozess, sodass kein unsichtbares Setup im Task-Manager bleibt.

Der Updater fordert die Setups dieser Installation zum normalen Schließen auf und wartet vor dem Ersetzen von Dateien auf ihr Ende. Dateiidentität und aktuelle Prozesslisten ersetzen das Vertrauen auf eine alte PID. Laufende Vorgänge bleiben geschützt; Prozesse werden nicht erzwungen beendet.

Kumulatives Update mit allen Änderungen der 2.1.9.4: keine BBS-Versions-/JAR-Hash-Sperre; offizielle openOMSI-Server 0.3.33 und 0.3.34; Spieler und Server benötigen passende Protokolle. Einstellungen, Firma, Einladung und Serverauswahl bleiben erhalten. Spiele und Host-Anwendungen schließen und Atualizar-Bridge.exe starten. Ein altes, bereits unsichtbar hängendes Setup muss für diese erste Installation eventuell einmal im Task-Manager beendet werden.

## Validation

Portable handoff tests cover the launching Setup, multiple instances, a newly opened instance, already closed processes, access failures and busy-operation timeout. Portable tests/vet, Windows cross-builds and package integrity pass locally. Native Windows UI/process execution remains to be tested. Server compatibility and BCS tests from 2.1.9.4 are retained.
