# OpenOmsi + BBS 2.0.2-dev.4 — automatic host

- Adds **HostAgent.exe**, accessible through Setup's **Company / server** button.
- Configures maps and fleets in a native PT/EN/DE window, with installed-map discovery, bulk bus selection, existing JSON import and separate ports/options per map.
- Starts a dedicated native openOMSI server when a player requests a registered map. Simultaneous requests reuse the same process; empty maps can stop after a configurable interval.
- Publishes verified tunnel addresses at a stable directory URL. A player JSON can bootstrap the directory once and remains usable across tunnel rotation.
- Preserves permissive multiplayer without local hash gates. Direct/manual legacy profiles remain supported.
- Includes the directory service, setup guide, protocol regressions and native Windows interface checks. The host computer must stay on with its agent running. The external HTTPS directory requires one initial deployment/configuration.

Live validation with a deployed directory, BCS and two players is pending.
