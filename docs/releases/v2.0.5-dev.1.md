# 2.0.5-dev.1 — HostAgent: escolha do servidor

Versão de teste baseada na 2.0.4. Libera o caminho do servidor e o botão **Procurar**. A escolha externa fica salva para o próximo início do agente, inclusive em segundo plano e depois de trocar a pasta do pacote. Selecionar o servidor incluído restaura o padrão automático.

## Como usar

1. No HostAgent antigo, clique em **Parar agente** e feche a janela.
2. Extraia este ZIP inteiro em uma pasta nova e abra seu **HostAgent.exe**.
3. Confira os mapas e a configuração já recuperados. Use **Procurar** para selecionar um servidor compatível, ou mantenha o executável incluído.
4. Clique em **Salvar e iniciar agente**.

O diretório online, suas chaves e os mapas cadastrados são preservados. O JSON dos jogadores continua o mesmo.

## Escopo

O servidor incluído continua em **0.2.11-bbs-free1 / protocolo 6**. Este ZIP corrige a seleção no HostAgent; não atualiza a base para a 0.2.20 e não corrige os passageiros. Servidores externos continuam precisando do protocolo e do suporte a ônibus livres exigidos pela integração.

The server path and Browse button are editable. Saved custom server choices survive GUI/background restarts and package upgrades. Select the bundled executable again to restore automatic bundled-server updates. External servers still need compatible protocol and unrestricted player-bus support. The bundled simulation is unchanged.

Serverpfad und Durchsuchen sind freigegeben. Eine gespeicherte eigene Serverwahl bleibt beim Neustart, im Hintergrund und nach Paketupdates erhalten. Die Auswahl der enthaltenen EXE stellt automatische Paketupdates wieder her. Externe Server müssen weiterhin Protokoll und freie Spielerbusse unterstützen. Die enthaltene Simulation bleibt unverändert.
