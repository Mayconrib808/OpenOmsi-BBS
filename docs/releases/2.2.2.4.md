# OpenOMSI BCS Bridge 2.2.2.4 — OpenOMSI 0.3.47

## Português

Oito gravações fornecidas pelo proprietário: três pedidos de porta, duas reclamações de ponto perdido e três agradecimentos/despedidas, exclusivas para Português (Brasil). Primeira migração PTB ativa comentários e agradecimentos; escolhas posteriores e silêncio de passageiros são respeitados. A reclamação de ponto perdido ocorre uma vez por desembarque perdido, inclusive quando o ônibus nunca parou. Pedidos de porta esperam dois segundos, cancelam ao abrir a saída correta e exigem vaga para embarcar. WAV PCM mono 24 kHz, normalização de duas passagens a -16 LUFS, reserva de pico -4 dBTP, ganho 1,5 e alcance 18 m para pedidos ao motorista.

A versão 2.2.2.3 trouxe as rotinas de passageiros da 0.3.47, mantendo o motor e launcher na base 0.3.46. A 2.2.2.4 integra a base completa upstream v0.3.47 (`8c4a0d3fd4439e49d18c2812bbd4d91cdd0af7f6`) e recompila jogo, launcher e servidor da mesma origem. A versão mostrada no lobby vem da API real do launcher, coberta por teste.

A rede utiliza protocolo 16. O servidor P16 e os hosts correspondentes são adicionados separadamente. Os executáveis completos dos hosts antigos e os servidores P14/P15 são preservados byte a byte. Preferências do host gerenciado são copiadas para arquivos P16 próprios, incluindo opções desativadas e dados privados desconhecidos; configurações P16 existentes são preservadas em atualizações posteriores. Servidores independentes não são trocados automaticamente.

Permanecem as opções de passageiros ativadas na primeira migração, as conexões cooperativas e as correções de troca de motorista, câmera, skins e áudio. As roupas extras continuam removidas. Mantidos o atualizador x64, restauração em disco, progresso visível e verificação completa. Todos os participantes da mesma sessão precisam usar protocolo compatível. Testes automatizados não comprovam comportamento visual no jogo ou uma sessão real entre dois PCs.

## English

Eight owner-provided recordings are exclusive to Brazilian Portuguese: three door requests, two missed-stop complaints and three thanks/farewells. First PTB migration enables these reactions, preserving later opt-outs and passenger mute. A missed alighting stop prompts one complaint, including when the bus never stopped. Door requests wait two seconds, cancel when the requested exit opens, and require available capacity for boarding. Mono PCM WAV 24 kHz, two-pass -16 LUFS normalization with -4 dBTP headroom, 1.5 request gain and 18 m range.

2.2.2.3 backported passenger routines from 0.3.47 while retaining the 0.3.46 engine and launcher. 2.2.2.4 integrates the full upstream v0.3.47 base and rebuilds game, launcher and server from the same source. The lobby displays the actual launcher bootstrap API version, covered by a regression test.

Networking uses protocol 16. Matching P16 server and companion hosts are added separately. Complete legacy host executables and P14/P15 servers are retained byte for byte. Managed host preferences are copied into separate P16 files, preserving explicit false values and unknown private fields. Later updates preserve existing P16 preferences. Independently selected servers remain independent.

Retains first-migration passenger defaults, cooperative connections, driver transfer, camera, skins and audio fixes, removal of extra clothes, and the x64 updater with disk rollback, visible progress and complete installation verification. Session participants need matching protocols. Automated checks do not establish visual gameplay or a real two-PC session.

## Deutsch

Acht bereitgestellte Aufnahmen ausschließlich für brasilianisches Portugiesisch: drei Türbitten, zwei Beschwerden und drei Dankes-/Abschiedsaufnahmen. Erste PTB-Migration aktiviert die Reaktionen; spätere Entscheidungen und Stummschaltung bleiben erhalten. Pro verpasstem Ausstieg wird einmal gesprochen, auch ohne vorherigen Halt. Türbitten warten zwei Sekunden, enden bei geöffneter angeforderter Tür und setzen beim Einstieg freie Kapazität voraus. Mono-PCM-WAV mit 24 kHz, Zweipass-Normalisierung auf -16 LUFS mit -4 dBTP Reserve, Verstärkung 1,5 und Reichweite 18 m für Fahrerbitten.

2.2.2.3 übernahm Fahrgastroutinen aus 0.3.47 auf Basis des Motors und Launchers 0.3.46. 2.2.2.4 integriert die vollständige Upstream-Basis v0.3.47 und baut Spiel, Launcher und Server aus derselben Quelle. Die Lobby zeigt die tatsächliche Version aus der Launcher-API; dies wird durch einen Regressionstest geprüft.

Die Netzwerkversion nutzt Protokoll 16. Passender Server und zusätzliche P16-Hosts werden separat ergänzt. Die vollständigen bisherigen Hosts und P14/P15-Server bleiben bytegleich erhalten. Einstellungen verwalteter Hosts werden in eigene P16-Dateien kopiert; ausgeschaltete Optionen und unbekannte private Felder bleiben erhalten. Spätere Updates erhalten vorhandene P16-Dateien. Unabhängig gewählte Server werden nicht automatisch ersetzt.

Aktive Fahrgastoptionen bei erster Migration, Koop-Anschlüsse, Fahrerwechsel-, Kamera-, Skin- und Audiokorrekturen bleiben erhalten. Zusätzliche Kleidung bleibt entfernt. Der x64-Updater behält Datenträgersicherung, sichtbaren Fortschritt und vollständige Installationsprüfung. Sitzungsteilnehmer benötigen kompatible Protokolle. Automatische Tests ersetzen weder eine Sichtprüfung im Spiel noch eine reale Zwei-PC-Sitzung.
