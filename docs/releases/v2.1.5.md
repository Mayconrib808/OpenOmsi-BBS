# 2.1.5

Readme files and human-readable documentation may be edited or missing without
blocking Setup, the runtime, or the standalone updater. The existing SHA256
manifest stays required. Executables, scripts, runtime configuration, path checks,
and integrity/control manifests retain their checks.

Opening Setup only loads saved settings. It neither prepares the BCS integration
nor checks bridge activation state automatically. Save and activate and Check
status perform these actions only when explicitly clicked. Optional update
checking still follows its saved checkbox.

The previous 2.1.4 download button checks package integrity before downloading,
so an installation already blocked by a changed readme must receive this fix
once through the standalone updater or the manual overlay. Other installations
can use the update button normally.

Candidate checks cover changed/missing documentation, executable tampering,
script/configuration/control-file tampering, absent SHA256 manifest, traversal,
the Windows child-process launcher, and the Windows GUI smoke check.
