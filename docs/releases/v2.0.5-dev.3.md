# 2.0.5-dev.3 — espera do servidor automático

Ao iniciar uma viagem que precisava abrir um mapa, um limite externo de 12 segundos podia interromper a espera e mostrar `context deadline exceeded`, mesmo que o servidor estivesse carregando normalmente. A entrada usa agora o orçamento completo de inicialização, de até 15 minutos, e continua aceitando cancelamento.

O erro já existia no fluxo anterior, mas era menos visível com um servidor já pronto. Esta correção permite esperar um início a frio; não garante que qualquer falha de mapa, servidor ou rede seja resolvida apenas esperando mais.

O servidor `0.2.20-bbs-free2` e os mapas/configurações não mudaram. O servidor é reutilizado do artefato já testado da dev.2, com os hashes/proveniência verificados. Esta versão ainda não remove a necessidade da adaptação nativa para ônibus livres; esse trabalho continua separado.

Atualização: pare o agente antigo, extraia este ZIP, abra o HostAgent e selecione o openomsi.exe da pasta server contida em app deste pacote. Salve e inicie o agente. JSON dos jogadores, mapas, portas e Cloudflare continuam iguais.

Regressões: inicialização que passa de 12 segundos, erro de servidor, servidor já pronto e cancelamento do chamador. Não substituem uma viagem real no BCS.
