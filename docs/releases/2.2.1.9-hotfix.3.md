# 2.2.1.9 Hotfix 3

Repairs the localized distribution's Setup update configuration. The previous localized ZIP was compiled without the deployed update origin and displayed “Distribution awaiting configuration” on every PC. The signed update feed still pointed to the earlier Hotfix 2 installer, without the localized BCS driver correction.

- Restores automatic and manual signed update checks in Setup, with a new release sequence so the earlier installer cannot be offered as an upgrade.
- Includes the BCS driver identity correction for “Bus Company Simulator” and “Simulador de Companhia de Autobuses”, preserving the saved driver data.
- Includes Setup's correction for reading the OMSI 2 folder before Save/Activate.
- Uses the exact authenticated Hotfix 2 Coop archive for updates. The localized source branch's stale Coop 12 manifest is replaced with the matching Hotfix 2 manifest.
- Retains complete HostAgent, CompanyHost, the plugin helper, modified game, audio, P14 and P15 server bytes.

Validation: Bridge regression tests, Windows compilation and resource verification, actual Setup automatic/manual checks against the signed live feed, and actual retained host UI controls. A complete two-PC BCS trip remains untested for this release.
