# Bridge 2.2.0.3-hotfix.1

The Setup displays a green/yellow Server status lamp and an explicit manual refresh button in Portuguese, English and German. It checks immediately on opening and every five seconds without blocking the interface. The local HostAgent must answer its authenticated loopback status endpoint, report no directory error and have an available map; a fresh directory read must also confirm its presence. An offline map with an online agent is ready on demand and shows green. Offline agents, unavailable checks, disabled maps and configuration problems show yellow. Read-only GET requests never wake a map or change settings. Player PCs without local host settings may monitor the enrolled company profile.

Only Setup is rebuilt. Six other release binaries, including the full P15 HostAgent/CompanyHost, and the Coop 9 game and dynamic 0.3.39 server retain their exact 2.2.0.3 hashes. The cumulative updater continues to pin the same complete Coop archive for older installations.
