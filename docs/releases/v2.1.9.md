# OpenOMSI BCS Bridge 2.1.9

## Português

Atualização cumulativa: a 2.1.9 pode ser instalada diretamente sobre a 2.1.8 comum ou sobre a 2.1.8-hotfix.1. Não é necessário instalar o hotfix intermediário primeiro.

Compatibilidade com o Bus Company Simulator 5.0.2.0, lançado em 14/10/2026.
O JAR oficial 5.0.2.0 validado tem SHA-256 `bfbf51cbb9033b130ecd4bebd41e1d04b926d8ef6c578737f1363a3146b196c6`.
A classe de log usada pela integração (`bbs/f.class`) continua byte a byte igual à versão previamente validada, portanto a Bridge mantém o mesmo ajuste estreito de Próxima viagem e passa a aceitar os dois builds oficiais conhecidos. Builds desconhecidos continuam recusados sem alteração do JAR.

Também incorpora integralmente o `2.1.8-hotfix.1`: o atualizador deixa de falhar com a mensagem de que o processo informado não é o Setup desta instalação quando o PID de handoff já encerrou, foi reciclado ou o mesmo `Setup.exe` é alcançado por alias/junção/hardlink. A verificação real de processos continua sendo refeita imediatamente antes de qualquer gravação.

Ao migrar entre builds do BCS, um backup antigo de `busbetrieb-simulator.jar` não é sobrescrito. Se o backup legado pertencer a outro build, a 2.1.9 cria um backup adicional identificado pelo início do SHA-256 do JAR atual.

Não distribui o JAR do BCS nem classes originais da PeDePe; o Setup continua reconstruindo somente o delta de comunicação validado localmente.

## English

Cumulative update: 2.1.9 can be installed directly over the regular 2.1.8 release or over 2.1.8-hotfix.1. Installing the intermediate hotfix first is not required.

Adds compatibility with Bus Company Simulator 5.0.2.0. The validated official JAR SHA-256 is `bfbf51cbb9033b130ecd4bebd41e1d04b926d8ef6c578737f1363a3146b196c6`.
The logger class used by the integration is byte-identical to the previously validated build, so the same narrow next-trip logger delta is retained while both known official vendor builds are accepted. Unknown builds remain rejected without modifying the JAR.

This release also includes the complete `2.1.8-hotfix.1` updater handoff fix. Stale/recycled handoff PIDs and equivalent paths to the same Setup executable no longer trigger a false installation mismatch, while the updater still performs a fresh real-process safety scan immediately before writes.

Existing backups from another BCS build are preserved; a build-specific backup is created for the current JAR when necessary.

## Deutsch

Kumulatives Update: 2.1.9 kann direkt über die normale 2.1.8 oder über 2.1.8-hotfix.1 installiert werden. Der Zwischen-Hotfix muss nicht zuerst installiert werden.

Fügt Unterstützung für Bus Company Simulator 5.0.2.0 hinzu. SHA-256 der geprüften offiziellen JAR-Datei: `bfbf51cbb9033b130ecd4bebd41e1d04b926d8ef6c578737f1363a3146b196c6`.
Die für die Integration verwendete Logger-Klasse ist byte-identisch mit dem zuvor geprüften Build. Deshalb bleibt derselbe eng begrenzte Nächste-Fahrt-Logger-Patch erhalten, während beide bekannten offiziellen BCS-Builds akzeptiert werden. Unbekannte Builds werden weiterhin ohne Änderung der JAR-Datei abgelehnt.

Außerdem ist der vollständige `2.1.8-hotfix.1` für die Übergabe an den Updater enthalten. Veraltete/wiederverwendete PIDs und alternative Pfade zur selben Setup-Datei lösen keinen falschen Installationsfehler mehr aus; unmittelbar vor Schreibvorgängen erfolgt weiterhin eine neue Prozessprüfung.

Backups eines älteren BCS-Builds bleiben erhalten. Falls nötig, wird für den aktuellen Build ein zusätzliches, build-spezifisches Backup angelegt.
