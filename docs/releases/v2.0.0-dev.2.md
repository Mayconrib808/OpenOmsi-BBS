# OpenOmsi + BBS 2.0.0-dev.2

Development package for optional company multiplayer and automatic company-clock synchronization. This is not a certified stable release.

Use Setup option 9 with session date `company` and the company's BCS time shift. Start the dedicated server with the included `CompanyHost.exe`. Read [COMPANY_CLOCK.md](../COMPANY_CLOCK.md) for one-time setup, migration and recovery behavior.

Runtime compatibility remains OpenOMSI 0.2.0 / protocol 6 and the existing BCS integration. No original game, server, bus, map or BCS plugin is bundled. Windows native helper tests and Linux source checks must pass before the development package is offered. Two-player physical buses, boarding and BCS evaluations still require real validation.
