# OpenOMSI BCS Bridge 2.1.9.7

## Português

Ativa a transferência nativa de ônibus e pinturas do openOMSI 0.3.38: o motorista envia os arquivos usados pelo seu ônibus ao servidor e os outros jogadores os recebem para ver o mesmo modelo e a mesma pintura. Durante o carregamento, o jogo pode mostrar uma caixa com o progresso; se o modelo não estiver disponível, mostra um substituto identificado.

O HostAgent detecta o servidor 0.3.38 ou superior, libera uploads e encaminha o canal de arquivos pelo mesmo endereço da empresa. Os nomes reais e as impressões digitais dos ônibus são preservados. As transferências têm limite próprio de conexões e quadros; não ocupam vagas dos jogadores. Criptografia, autenticação da sessão, hashes, quarentena, retomada e armazenamento ficam a cargo do openOMSI original. O compartilhamento de mapas continua desligado; cada jogador instala o mapa e suas dependências.

A ativação é automática quando o jogador atualizado encontra um host atualizado com servidor compatível. Servidores anteriores mantêm a adaptação de nomes, os substitutos locais e a resposta normal de uploads desativados da 2.1.9.6. Os protocolos 6, 7 e 14 continuam aceitos; isso não dá os recursos da 0.3.38 a jogos antigos.

**Instalação:** atualização cumulativa da linha 2.1, preservando empresa, convite, pastas e preferências. Feche BCS, openOMSI, Setup, HostAgent e CompanyHost, execute `Atualizar-Bridge.exe` e reabra o HostAgent e o BCS. Atualize a Bridge no computador do host e nos jogadores. Para a transferência de ônibus, use openOMSI 0.3.38 ou superior nos jogadores e no servidor, em versões compatíveis. A Bridge não substitui o jogo nem o servidor; selecione o servidor dedicado atualizado no HostAgent. A 0.3.38 foi publicada como beta de testes.

## English

Enables openOMSI 0.3.38 native bus and livery transfers. Drivers send the files their bus uses to the server; other players receive the exact model and paint. A progress box can appear while it loads, or a labelled stand-in when unavailable.

HostAgent automatically detects a 0.3.38 or later server, enables uploads and carries the encrypted file stream through the existing company address. Original bus paths and fingerprints are preserved. File streams have independent capacity and bounded frames, without using player slots. The unchanged native game handles session proofs, hashes, quarantine, resuming and sealed storage. Map sharing remains disabled: players install the map and its dependencies locally. Updated players activate the native channel when the updated host advertises it.

Older servers retain filename adaptation, local stand-ins and the normal uploads-disabled response from 2.1.9.6. Protocols 6, 7 and 14 remain supported; older games do not gain the new viewer.

**Installation:** cumulative 2.1 update preserving company, invitation, paths and preferences. Close BCS, openOMSI, Setup, HostAgent and CompanyHost, run `Atualizar-Bridge.exe`, then reopen HostAgent and BCS. Update the host and players. This feature requires compatible openOMSI 0.3.38 or later game and dedicated server versions. The Bridge does not replace them; select the updated dedicated server in HostAgent. Upstream 0.3.38 is a testing beta.

## Deutsch

Aktiviert die native Bus- und Lackierungsübertragung von openOMSI 0.3.38: Der Fahrer sendet die von seinem Bus verwendeten Dateien an den Server. Andere Spieler erhalten dasselbe Modell und dieselbe Lackierung. Währenddessen kann eine Box mit Fortschritt erscheinen; bei nicht verfügbarem Modell ein gekennzeichnetes Ersatzfahrzeug.

HostAgent erkennt Server ab 0.3.38 automatisch, aktiviert Uploads und leitet den verschlüsselten Dateikanal über die bestehende Firmenadresse weiter. Echte Buspfade und Fingerprints bleiben erhalten. Dateiverbindungen haben eigene Kapazitäts- und Framegrenzen und belegen keine Spielerplätze. Das unveränderte openOMSI übernimmt Sitzungsnachweise, Hashes, Quarantäne, Fortsetzung und versiegelte Speicherung. Kartenfreigabe bleibt deaktiviert; jeder Spieler installiert Karte und Abhängigkeiten selbst. Aktualisierte Spieler aktivieren den nativen Kanal, wenn der aktualisierte Host ihn meldet.

Ältere Server behalten Namensanpassung, lokale Ersatzmodelle und die normale Upload-Ablehnung aus 2.1.9.6. Die Protokolle 6, 7 und 14 bleiben unterstützt; ältere Spiele erhalten dadurch keinen neuen Viewer.

**Installation:** kumulatives Update der Reihe 2.1. Firma, Einladung, Pfade und Einstellungen bleiben erhalten. BBS, openOMSI, Setup, HostAgent und CompanyHost schließen, `Atualizar-Bridge.exe` starten, danach HostAgent und BBS wieder öffnen. Host und Spieler aktualisieren. Dafür kompatible Spiel- und Serverversionen ab openOMSI 0.3.38 verwenden. Die Bridge ersetzt sie nicht; den aktualisierten dedizierten Server im HostAgent auswählen. openOMSI 0.3.38 ist eine Test-Beta.

## Validation scope

Automated transport regressions cover 128 KiB file frames independently of gameplay datagrams, fragmentation, ping, byte ordering, capacity exhaustion, shutdown, native bus identity, configuration isolation and legacy refusals. An independent encrypted client against the unmodified official 0.3.38 server checks its session proof, uploads a synthetic bus, livery and BMP texture, resumes an interrupted 1 MiB piece, and downloads identical content from a second client. It also checks disabled map sharing and rejection of bad hashes and disguised executable content. No proprietary OMSI or BCS content is used. These checks do not replace a complete BCS trip or a visual test with real buses.
