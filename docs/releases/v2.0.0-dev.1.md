# 2.0.0-dev.1 — company multiplayer development

First development build of administrator-defined company profiles, curated addon links and automatic joining of already hosted sessions when a BBS trip starts.

The client checks the session's map, game/protocol, clock, capacity and declared fleet; required local files are checked for missing, changed and extra content. A requirements page opens with administrator-provided download links. Host-world confirmation gates BBS readiness so failed or mismatched joining does not silently proceed as a solo trip.

Setup options 8 and 9 configure the player and generate company profiles. Multiplayer is disabled by default. The existing bridge trip mode remains available.

This build is retained as a CI development artifact. It is not an approved release and has no frozen live-tested binary manifest. Two-player bus rendering, boarding and BBS trip evaluation are still pending. See [MULTIPLAYER.md](../MULTIPLAYER.md) for configuration, boundaries and test cases.
