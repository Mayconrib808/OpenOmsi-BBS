# Pacote pessoal de integração Coop 7 / Bridge 2.2.0

Esta não é uma atualização publicada nem uma Bridge binária 2.2.0.1 recompilada. É a distribuição Bridge 2.2.0 original com o jogo Coop 7 recém-compilado substituindo somente a compilação Coop 6 no diretório `OpenOmsi Coop 0.3.38/programa/`.

Os binários de Bridge, Setup, Host, Adapter e dependências do Coop 6 foram preservados. O executável do Coop 7 é o do artefato GitHub Actions validado por hash. Como o atualizador automático 2.2.0 verifica hashes fixos da Coop 6, não use a função de atualização automática para instalar este ZIP pessoal. Para instalar, selecione `Usar Coop incluído` e `Salvar e ativar`.

Testes 41/41 (mais 1 ignorado por faltar conteúdo real instalado), autoteste e compilação Windows confirmados. Não há validação presencial de dois jogadores nem BCS.
