Instalar e começar

Tenha OMSI 2, BCS/BBS e openOMSI 0.2.0 para Windows x64 instalados. O pacote contém todos os componentes da ponte; os jogos e seus conteúdos são obtidos separadamente.

  1. Feche os jogos. Extraia todo o ZIP em uma pasta fixa. Para mudar de pasta, desative a instalação anterior pelo Setup dela.
  2. Abra Setup.exe, escolha seu idioma e informe a pasta do OMSI 2 original e o caminho de openomsi.exe.
  3. Escolha 2 — Ativar / atualizar e aceite a permissão do Windows. Não precisa procurar ou instalar um auxiliar separado.
  4. No BCS/BBS, vá a Definições → Definições avançadas → OMSI e deixe “Iniciar o OMSI mais depressa” desmarcado.
  5. No openOMSI, desative a sincronização com o relógio real. Inicie a viagem normalmente pelo BCS/BBS e aguarde o mapa carregar.
  6. No ponto final: pressione F9 → aguarde pelo menos 2 segundos → finalize no BCS/BBS com o openOMSI aberto.
Voltar ao OMSI original: feche os jogos e use 3 — Desativar no Setup desta pasta. O executável original não foi substituído.

Ajuda no próprio pacote

4: ver estado. 5: criar diagnóstico local. 6: conferir integridade. 7: abrir este guia. Para reportar problemas, use o Discord .zmaycon., com os pontos nas duas pontas. Revise o ZIP de diagnóstico antes de compartilhar; nada é enviado automaticamente.

O que precisa ficar claro

Projeto experimental e independente, sem aprovação ou suporte oficial da PeDePe ou dos demais fornecedores. A ponte não aplica patches aos executáveis, JARs ou DLLs originais. Ela atualiza o perfil Drivers/bbs.odr, cria seus próprios arquivos e configura um redirecionamento no Registro do Windows. Veja os efeitos locais e o aviso técnico.

Referência: openOMSI 0.2.0 x64 e BCS/BBS 5.0.0.1. Berlin-Spandau tem problema de carregamento registrado; use o OMSI original nesse caso. A data automática é a data local do Windows. O pacote foi preparado com testes automatizados; esses testes não comprovam uma viagem real, avaliação completa ou pagamento idêntico. Consulte a validação.

Install and start

  1. Install legitimate OMSI 2, BCS/BBS and openOMSI 0.2.0 Windows x64 separately. Close the games and extract the entire ZIP into a permanent folder.
  2. Run Setup.exe, select English and configure the original OMSI folder and openomsi.exe.
  3. Choose 2 — Activate / update and accept Windows permission. The bundled helper is installed automatically.
  4. In BCS/BBS Settings → Advanced settings → OMSI, leave “Start OMSI faster” unchecked. Disable real-time clock synchronisation in openOMSI.
  5. Start the trip through BCS/BBS. At the last stop: F9 → wait at least 2 seconds → finish in BCS/BBS while openOMSI remains open.

Close the games and use Setup option 3 to return to original OMSI. Before moving the package, deactivate through the old folder's Setup. Option 5 collects local diagnostics, 6 checks integrity, 7 opens this guide.

This is an unofficial experimental project without vendor approval. Original executables/JARs/DLLs are not patched; Drivers/bbs.odr, bridge files and a scoped Windows Registry redirect are written. No proprietary software or assets are supplied. Automated tests do not establish live BCS trip compatibility, rule acceptance or payment parity. See README, validation and credits. Berlin-Spandau has a recorded loading issue; the automatic date follows local Windows time. Discord: .zmaycon. (both dots).

Installieren und starten

  1. Installiere OMSI 2, BBS und openOMSI 0.2.0 für Windows x64 separat mit gültigen Lizenzen. Schließe die Spiele und entpacke die gesamte ZIP-Datei in einen festen Ordner.
  2. Starte Setup.exe, wähle Deutsch und gib den originalen OMSI-Ordner sowie den Pfad zu openomsi.exe an.
  3. Wähle 2 — Aktivieren / aktualisieren und bestätige die Windows-Abfrage. Das mitgelieferte Hilfsprogramm wird automatisch bereitgestellt.
  4. Unter BBS → Einstellungen → Erweiterte Einstellungen → OMSI muss „OMSI schneller starten“ deaktiviert sein. Deaktiviere die Echtzeitsynchronisierung in openOMSI.
  5. Starte die Fahrt über BBS. An der Endhaltestelle: F9 → mindestens 2 Sekunden warten → in BBS abschließen, während openOMSI geöffnet bleibt.

Mit Setup-Option 3 kehrst du nach dem Schließen der Spiele zum originalen OMSI zurück. Vor einem Ordnerwechsel im alten Setup deaktivieren. Option 5 erstellt lokale Diagnosen, 6 prüft die Integrität, 7 öffnet diese Anleitung.
