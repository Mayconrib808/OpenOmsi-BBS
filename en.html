Quick questions

Does a Berlin link work for Carrão City?

The company invitation routes both maps. A direct trycloudflare.com URL for Berlin points only to Berlin.

Can I use my DLSS/ReShade client?

Yes. In Setup choose Client → Manual and your compatible openomsi.exe. BCS must keep the PeDePeAdapter path.

How do I finish and start the next trip?

Use the native BCS flow, wait for its confirmation with the game open, then select Next trip and check the duty and display.

What if the host leaves?

Closing the game keeps the server while peers remain. Turning off the PC or losing Internet disconnects the session; a later join can elect another host.
