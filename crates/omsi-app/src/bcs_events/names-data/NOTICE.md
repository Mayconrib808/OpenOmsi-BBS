# International inspector appearance lookup data

Original: Jörg Michael, 2007–2008, nam_dict.txt 1.2 (2008-11-30). Retrieved from https://github.com/lead-ratings/gender-guesser at 820d86f9f652ef064e784998b516a8aa2abefe3c, gender_guesser/data/nam_dict.txt.

The exact original document is included as nam_dict.txt.gz (gzip, no edits), together with the full GFDL 1.2 license are included. No invariant sections or cover texts. names.tsv is a modified lookup by OpenOMSI BCS Bridge contributors (2026): only unambiguous M/F records retained, plus separators expanded, diacritics removed and names lowercased. The derived data is licensed under GFDL 1.2 or later.

Used only to select a fictional character model. This estimates name usage and does not establish identity or sex. Ambiguous and missing names remain unknown and can be overridden by inspector ID.
