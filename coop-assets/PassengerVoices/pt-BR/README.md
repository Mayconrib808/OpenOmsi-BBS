# Vozes de passageiros — Português (Brasil)

Oito gravações fornecidas pelo proprietário do projeto em 2026-11-02 para inclusão no jogo. Três pedidos de porta, duas reclamações de ponto perdido e três despedidas/agradecimentos. Uso exclusivo quando o idioma do jogo é PTB. Os arquivos originais são identificados por SHA-256 no manifesto.

Conversão AAC para WAV PCM mono 24 kHz com normalização EBU R128 de duas passagens, alvo -16 LUFS e pico verdadeiro máximo -4 dBTP (reserva para o ganho do mixer). Pedidos ao motorista recebem alcance de 18 m e ganho 1,5 no mixer; o volume geral e a opção de silenciar passageiros continuam respeitados. A audibilidade em cada ônibus precisa ser conferida no jogo.
