BBS+OpenOmsi Multiplayer — 3.0.2-dev.4
Development preview for private testing, not a public release.

1. Extract the complete ZIP into a permanent folder. No Bridge 2.0/2.x installation is required. OMSI 2 and BCS must be installed normally.
2. Open Setup.exe, choose your language and save a company invitation or create a room.
3. Close BCS and click Configure BCS. Finish setup, then start the trip in BCS.

Setup installs the 3.x helper when configuring BCS and downloads the openOMSI client if needed (internet required for initial setup).
No BCS JAR or DLL is supplied or modified. Next trip remains pending. Update checks use only 3.x GitHub releases; the dedicated signed feed still requires publication.
Program controls: disable multiplayer for solo openOMSI; disable the program with BCS closed to restore original OMSI launching.
The update-files ZIP is only for an existing 3.x installation. Keep its config folder.
This independent project is not an official PeDePe product.
