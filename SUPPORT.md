# Support

For bridge problems, open an Issue in this repository with the bridge version, openOMSI version, BCS/BBS version, Windows version, map and route, expected behaviour and observed behaviour. The project's existing Discord contact is **`.zmaycon.`**; both dots belong to the handle.

The repository currently provides source and development components, not a complete runtime package. Read [helper provenance](docs/HELPER_PROVENANCE.md) before attempting a local installation.

Setup option 5 can produce a local diagnostic ZIP from a complete runtime package. It is not uploaded automatically. The archive can contain account identifiers, machine paths, driver counters, logs and selected local timetable files. Review and redact it before sharing. Share only what you have permission to distribute; do not publish paid map/DLC content or proprietary binaries. A small redacted excerpt and steps to reproduce are often enough.

Issues concerning this independent bridge belong here. This repository does not provide PeDePe, openOMSI, Aerosoft or Steam product support and does not assert that those projects support it.
