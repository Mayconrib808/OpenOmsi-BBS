# OpenOmsi + BBS directory

This service publishes company player profiles at a stable HTTPS URL and queues requests for the host agent. It does not run the game or proxy game traffic.

Deploy `wrangler.jsonc` with Cloudflare Wrangler. Set the private `HOST_KEY` secret before deployment; use the key generated by **HostAgent.exe → Copy key**. No credential belongs in this repository or a player profile. Configure the returned Worker URL in the host application. See [the host guide](../docs/AUTO_HOST.md).

Run protocol regressions with `node --test test/room.test.js`. The tests use an in-memory storage adapter; they do not establish that a deployed Cloudflare account, tunnel or game installation works.

| Endpoint under `/rooms/<32-hex-code>` | Access | Purpose |
| --- | --- | --- |
| `GET /profile` | Room invite | Current company JSON |
| `POST /wake` | Room invite | Request a registered map |
| `GET /sessions/<id>` | Room invite | Fresh session readiness |
| `POST /publish` | Bearer host key | Replace the public profile |
| `POST /heartbeat` | Bearer host key | Publish host/session status |
| `GET /requests` | Bearer host key | Read recent deduplicated demands |

Host heartbeats expire after 45 seconds. Wake requests expire after 120 seconds and collapse by session ID. The client refreshes its request while waiting. The host verifies the native tunnel and world before advertising the map online. Responses use `Cache-Control: no-store`. Legacy profiles are split into 64 KiB storage values and committed as one snapshot.
